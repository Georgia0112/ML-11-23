1. 乳癌影像特徵二元分類（課堂實作一）
資料來源：UCI Breast Cancer Wisconsin (Diagnostic) 資料集（亦為 scikit-learn 內建資料副本），共 569 筆樣本（良性 357 筆、惡性 212 筆），30 項原始影像特徵；
實作中選用 6 項特徵（mean_radius、mean_texture、mean_smoothness、mean_compactness、worst_concavity、worst_concave_points）預測二元目標變數 malignant（1 = 惡性，0 = 良性）。
2. 糖尿病一年後病程指標迴歸（學生作業二）
資料來源：scikit-learn Diabetes 資料集（原始未縮放特徵版本），共 442 筆樣本，使用 10 項預測變數（age、sex、bmi、bp 及 s1–s6）預測連續型因變數 progression（一年後病程進展數值指標）。
